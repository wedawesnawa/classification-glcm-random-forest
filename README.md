# Face Expression Classification Using GLCM and Random Forest

This repository contains the results of a research project on **facial expression classification** into three categories: **happy, sad, and angry**. The project uses **Gray-Level Co-occurrence Matrix (GLCM)** for feature extraction and **Random Forest** as the machine learning classification algorithm.

## Project Overview

The project consists of several main files:

* **`klasifikasi_ekspresi.py`** — Used for training and testing the machine learning model.
* **`main.py`** — A web application built with **Streamlit** and **Bootstrap** for facial expression classification.
* **`datasets(3s).zip`** — The dataset used for training and testing the model.

## Tech Stack

* **Python**
* **Streamlit**
* **Bootstrap**
* **GLCM (Gray-Level Co-occurrence Matrix)**
* **Random Forest**
